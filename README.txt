# Help Andy Heal 🐾

A simple static fundraising website for Andy, a 10-year-old Shih Tzu–Poodle mix.

## Files
- index.html — the complete website
- assets/ — Andy's photos, medical records, and donation QR codes

## How to use
1. Open `index.html` in a browser to preview it.
2. To publish it, upload the whole `andy_campaign` folder to a static hosting service such as GitHub Pages, Netlify, Vercel, or your web host.
3. Keep the `assets` folder beside `index.html`.

## Important
The progress bar is intentionally set to 0% because no amount raised was provided. Update the progress width in `index.html` when you know the amount raised.
